# SOP_07: Post-Conversion Fixes

## Purpose

This directive guides the agent in identifying and fixing common issues that remain after MinerU PDF conversion and automated post-processing. While the `MarkdownPostProcessor` handles many issues automatically, some problems require manual review and correction.

## Scope

Applies to markdown documents generated by the PDF to Markdown converter that contain:
- Academic papers with mathematical formulas
- Documents with bibliographic references
- Technical content with complex formatting

---

## 1. Math Formula Fixes

### 1.1 Missing Dollar Sign Delimiters

**Problem:** LaTeX commands appear without `$` delimiters.

**Pattern to find:**
```
\frac{...}{...}  (without $ around it)
\mathcal{...}    (without $ around it)
\partial         (without $ around it)
```

**Fix:** Wrap in `$...$` for inline or `$$...$$` for display math.

**Example:**
```markdown
# Before (broken)
The weighting factor = \frac{1}{d_e^2 + \epsilon}

# After (fixed)
The weighting factor $w_e = \frac{1}{d_e^2 + \epsilon}$
```

### 1.2 Excessive Spacing in Math

**Problem:** Spaces inserted around subscripts/superscripts.

**Pattern to find:**
```
$d _ { e }$     (spaces around _ and {})
$x ^ { 2 }$     (spaces around ^ and {})
```

**Fix:** Remove spaces: `$d_{e}$`, `$x^{2}$`

### 1.3 Lost Variable Names

**Problem:** MinerU sometimes drops the variable name before `=`.

**Pattern to find:**
```
$= \frac{...}{...}$   (missing variable before =)
```

**Fix:** Check original PDF and add the missing variable name.

**Example:**
```markdown
# Before (broken)
by a weighting factor $= \frac{1}{d_e^2 + \epsilon}$

# After (fixed - check PDF for actual variable)
by a weighting factor $w_e = \frac{1}{d_e^2 + \epsilon}$
```

### 1.4 Broken Display Math

**Problem:** Display math blocks missing proper delimiters or split.

**Pattern to find:**
```
$$
some content
(missing closing $$)
```

**Fix:** Ensure matching `$$` delimiters on separate lines.

## 2. Reference Section Fixes

### 2.1 Concatenated References

**Problem:** Multiple references run together on same line.

**Pattern to find:**
```
...paper title. https://doi.org/10.1234/5678Author Name. 2021. Next paper...
```

**Fix:** Add blank line between references:
```markdown
...paper title. https://doi.org/10.1234/5678

Author Name. 2021. Next paper...
```

### 2.2 Split Author Names

**Problem:** Author names broken across lines.

**Pattern to find:**
```
Smith, J. and N.
Venkata Reddy. 2020...
```

**Fix:** Join on single line:
```markdown
Smith, J. and N. Venkata Reddy. 2020...
```

### 2.3 Broken DOI URLs

**Problem:** DOI URLs split across lines or missing parts.

**Pattern to find:**
```
https://doi.org/10.
1109/TVCG.2003.1260744
```

**Fix:** Join into single URL:
```markdown
https://doi.org/10.1109/TVCG.2003.1260744
```

### 2.4 Orphaned DOI Fragments

**Problem:** DOI path appears on its own line without URL prefix.

**Pattern to find:**
```
previous content.
1109/TVCG.2003.1260744
Next reference...
```

**Fix:** Either join with previous DOI URL or remove if duplicate.

### 2.5 Figure Captions in References

**Problem:** Figure captions get mixed into references section.

**Pattern to find:**
```
# REFERENCES
...reference content...
![](images/xxx.jpg)
Fig. 14. Some caption text
...more references...
```

**Fix:** Remove image links and captions from references section.

## 3. URL Fixes

### 3.1 Math Symbols in URLs

**Problem:** Query parameters converted to math symbols.

**Pattern to find:**
```
http://example.com/page$\subset$id=123
```

**Fix:** Replace `$\subset$` with `?`:
```markdown
http://example.com/page?id=123
```

### 3.2 Spaces in URL Paths

**Problem:** Spaces inserted mid-URL.

**Pattern to find:**
```
http://dl.acm.org/ citation.cfm?id=123
```

**Fix:** Remove space:
```markdown
http://dl.acm.org/citation.cfm?id=123
```

## 5. Structural Fixes

### 5.1 DOI Fragments as Headings

**Problem:** DOI paths incorrectly formatted as markdown headings.

**Pattern to find:**
```markdown
# 1109/TVCG.2003.1260744

Next paragraph...
```

**Fix:** Remove the heading marker or join with previous DOI URL.

### 5.2 Broken Paragraph Continuations

**Problem:** Paragraphs split incorrectly.

**Pattern to find:**
```
...end of sentence that continues on
next line without reason.
```

**Fix:** Join into proper flowing paragraph.

### 5.3 Missing Section Headings

**Problem:** Section numbers detected but heading text lost.

**Pattern to find:**
```markdown
## 4.5

The content starts here...
```

**Fix:** Add heading text from original PDF:
```markdown
## 4.5 Shortest Path Computation

The content starts here...
```

## 6. Agent Workflow for Fixes

### Step 1: Automated Review
Run the post-processor validation:
```python
from Execution.processors.post_processor import MarkdownPostProcessor

processor = MarkdownPostProcessor()
issues = processor.validate_math(content)
for issue in issues:
    print(f"Line {issue['line']}: {issue['message']}")
```

### Step 2: Prioritized Manual Review

1. **Critical:** Math formulas (especially equations with results)
2. **High:** Reference section integrity
3. **Medium:** URL validity
4. **Low:** Cosmetic formatting

### Step 3: Verification

After fixes, verify:
- [ ] All math formulas render correctly in markdown preview
- [ ] All DOI links are clickable and valid
- [ ] References are properly separated
- [ ] No orphaned fragments remain

## 10. Specific Patterns from Recent Conversions

These patterns have been identified from actual conversions and require manual attention:

### 10.1 Spaced Decimal Numbers

**Problem:** OCR inserts spaces within decimal numbers in math mode.

**Pattern to find:**
```markdown
$0. 2 5$      (should be $0.25$)
$- 0. 6 2 5$  (should be $-0.625$)
$1 4 \times 2 6$  (should be $14 \times 26$)
```

**Fix:** Remove internal spaces from numbers.

**Example:**
```markdown
# Before
$x^2 + y^2 + z^2 = 0. 2 5$

# After
$x^2 + y^2 + z^2 = 0.25$
```

### 10.2 Spaced Operators in Formulas

**Problem:** Spaces around operators break math rendering.

**Pattern to find:**
```markdown
$P _ { i j } = 1 \dot { - } 0. 2$
$4 d ^ { 6 } - 1 7 d ^ { 4 }$
```

**Fix:** Clean up to proper LaTeX:
```markdown
$P_{ij} = 1 - 0.2$
$4d^6 - 17d^4$
```

### 10.3 Garbled Set/Union Notation

**Problem:** Complex mathematical notation gets corrupted.

**Pattern to find:**
```markdown
$S = \bigcup_{\cdot \ \cdot \.} ( { \bigsqcup}_{(} R_{i} \cap R_{j} )$
followed by plaintext: 1,...,;i j M i j= ≠
```

**Fix:** Reconstruct the proper formula:
```markdown
$S = \bigcup_{i,j=1,...,M; i \neq j} (\overline{R_i} \cap \overline{R_j})$
```

### 10.4 Garbled Triangle/Vertex Lists

**Problem:** Subscript notation in lists gets scrambled.

**Pattern to find:**
```markdown
Triangles: jl il jkl il ikl jklm m m m m m,,;,,
```

**Fix:** Restore proper subscript notation:
```markdown
Triangles: $m_{jl}, m_{il}, m_{jkl}$; $m_{il}, m_{ikl}, m_{jkl}$
```

### 10.5 Copyright Symbols as Math

**Problem:** Copyright symbols converted to math notation.

**Pattern to find:**
```markdown
$\mathbb{C} 1 9 9 5$
```

**Fix:** Replace with proper copyright:
```markdown
©1995
```

### 10.6 Function/Pseudocode Formatting

**Problem:** Pseudocode functions mixed with math mode incorrectly.

**Pattern to find:**
```markdown
Sigmoid (d){ if abs $( d ) > 1$ then return 0 else return 1 $( 4 d ^ { 6 } - 1 7 d ^ { 4 } + 2 2 d ^ { 2 } ) / 9$
```

**Fix:** Clean up for readability:
```markdown
Sigmoid(d) { if abs$(d) > 1$ then return 0 else return $1 - (4d^6 - 17d^4 + 22d^2)/9$ }
```

### 10.7 Greek Letter Variables

**Problem:** Nu (ν) confused with v in vertex notation.

**Pattern to find:**
```markdown
$\nu I$ and $\nu 2$   (should be $v_1$ and $v_2$)
$\nu 4$              (should be $v_4$)
```

**Fix:** Convert to proper vertex subscript notation.

### 10.8 Set Notation with Spaced Coordinates

**Problem:** Set builder notation has excessive spacing.

**Pattern to find:**
```markdown
$\left\{ ( x, y, z ): - 0. 0 2 5 \leq x \leq 0. 6 2 5, - 0. 6 2 5 \leq y \leq 0. 6 2 5 \right\}$
```

**Fix:** Clean up spacing:
```markdown
$\{(x, y, z): -0.025 \leq x \leq 0.625, -0.625 \leq y \leq 0.625\}$
```

### 10.9 Vector/Bold Notation

**Problem:** Bold vector notation has extra formatting.

**Pattern to find:**
```markdown
$\pmb { p }$
$\pmb { p } _ { z }$
$\mathbf { - } \pmb { p } _ { z }$
```

**Fix:** Simplify:
```markdown
$\mathbf{p}$
$p_z$
$-p_z$
```

### 10.10 Epsilon/Error Notation

**Problem:** Epsilon symbols get mangled.

**Pattern to find:**
```markdown
$\pmb { \mathrm { \varepsilon } } = 1 / 2 5 6$
$\mathfrak { E }$
E (plaintext used instead of symbol)
```

**Fix:** Use consistent epsilon:
```markdown
$\varepsilon = 1/256$
```

### 10.11 Fraction Formatting Issues

**Problem:** Fractions have spacing or missing delimiters.

**Pattern to find:**
```markdown
edgeLength $/ ( 2 ^ { ( m + l ) } n ) \leq \mathfrak { E }$
```

**Fix:** 
```markdown
edgeLength$/( 2^{(m+1)} n ) \leq \varepsilon$
```

### 10.12 Duplicate Terms in Formulas

**Problem:** OCR produces duplicate terms in complex formulas.

**Pattern to find:**
```markdown
$m_{k l}, m_{j k l}, m_{j k l}, m_{t}$  (m_jkl duplicated)
```

**Fix:** Remove duplicates while preserving correct formula structure.

## 12. Automated Pattern Detection

For future post-processor enhancement, these regex patterns can help detect issues:

```python
# Spaced decimals in math
r'\$[^$]*\d\.\s+\d'

# Spaced subscripts
r'_\s*\{\s*\w+\s*\}'

# Copyright as math
r'\$\\mathbb\{C\}'

# Nu instead of v in vertex notation  
r'\$\\nu\s*[0-9IViv]'

# Plaintext after math (garbled formulas)
r'\$[^$]+\$[^$\n]*[a-z]\s+[a-z]\s+[A-Z]\s+[a-z]\s*='
```
